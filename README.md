# Cartoon Studio

Одна студия для коротких рисованных мультфильмов.
Вы меняете сцены, персонажей и звук, затем сохраняете MP4.

Первый проект уже открыт: Мира и Лея путешествуют к морю.
Он содержит три сцены и длится 18 секунд.
Персонажи придуманы для этого проекта.

## Запуск

Нужны [Node.js](https://nodejs.org/) 22.15 или новее и [FFmpeg](https://ffmpeg.org/download.html).
Команды `ffmpeg` и `ffprobe` должны быть доступны в терминале.

```bash
git clone https://github.com/ios3kov/Cartoon-Studio.git
cd Cartoon-Studio
npm ci
npm run setup:browser
npm run build
npm start
```

Откройте **http://127.0.0.1:4173**.
Для редактора и экспорта ключи ИИ не нужны.
Первое рисование занимает больше времени: студия готовит текстуры кистей.

Для разработки:

```bash
npm run dev
```

Адрес разработки — **http://127.0.0.1:5173**.
Одна команда запускает редактор и локальный сервер.

## Возможности

| Раздел | Что можно менять |
| --- | --- |
| Сцены | Порядок, длительность, место, подпись, камера, переход |
| Персонажи | Имя, причёска, цвета кожи, волос и одежды |
| Движение | Положение, размер, отражение, ходьба, приветствие, прыжок, поездка |
| Лицо | Радость, любопытство, удивление, спокойствие |
| Рисунок | Акварель, карандаш, пастель; горизонтальный или вертикальный кадр |
| Звук | Загрузка, начало, обрезка, громкость, повтор |
| Проект | Автосохранение, отмена, повтор, импорт, переносимый файл `.cartoon` |
| Видео | MP4, черновое качество или HD, прогресс, отмена, скачивание |
| История | Локальный черновик; дополнительная генерация через настроенный сервис ИИ |
| Озвучка | Загрузка записи; дополнительная генерация через настроенный сервис речи |

Студия поддерживает до 24 сцен и 120 секунд в одном проекте.
Можно использовать до восьми персонажей и 12 аудиодорожек.
Частота кадров: 12, 24 или 30.

## Сохранение и перенос

Автосохранение хранит последний проект в этом браузере.
Записи звука хранятся отдельно, на компьютере с сервером.

**Файл `.cartoon` содержит проект и все его аудиофайлы.**
Используйте его для переноса на другой компьютер.
Импорт сначала проверяет данные, затем восстанавливает звук.

JSON содержит только проект и ссылки на локальные аудиофайлы.
Он удобен для редактирования данных и запуска экспорта из терминала.
Для переноса проекта со звуком используйте `.cartoon`.

## Как устроено объединение

Мы подключили [p5.brush](https://github.com/acamposuribe/p5.brush) 3.0.0 как зависимость.
Библиотека рисует живописные текстуры через WebGL.
Студия сохраняет текстуры и использует их при сборке кадров.

Из [ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase) адаптированы функции движения, времени и покадрового экспорта.
Новый редактор работает с проверяемыми данными проекта.
Оригинальные человеческие персонажи заменяют единственного героя исходного примера.

Один движок рисует и предпросмотр, и итоговое видео.
Кадр зависит от времени и номера варианта проекта.
Экспорт не записывает экран: он рассчитывает кадры последовательно.

```text
src/shared/     Формат проекта, проверка данных, архивы
src/engine/     Кисти, персонажи, сцены, движение
src/App.tsx    Редактор
src/render.ts  Страница покадрового экспорта
server/        Аудиофайлы, очередь, FFmpeg, дополнительные сервисы
scripts/       Запуск разработки и экспорт из терминала
tests/         Проверки данных, сервера и браузера
```

Точные источники и лицензии указаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Дополнительные сервисы ИИ

Скопируйте `.env.example` в `.env`.
Для раскадровки задайте `AI_API_KEY`, `AI_MODEL` и при необходимости `AI_BASE_URL`.
Нужен совместимый интерфейс Chat Completions с ответом JSON.

Для озвучки задайте `TTS_API_KEY`, `TTS_MODEL` и при необходимости `TTS_BASE_URL`.
Интерфейс речи должен поддерживать `/audio/speech`.
Ключи остаются на локальном сервере.
Расходы определяет выбранный сервис.

Без настроек эти функции показывают понятное объяснение.
Локальный черновик работает без сети и использует шаблон.
Он не выдаётся за результат ИИ.

## Экспорт из терминала

Сначала сохраните JSON проекта через редактор и выполните сборку.

```bash
npm run render -- --project project.json --out out/movie.mp4 --preset hd
```

Готовый пример находится в `examples/seaside.cartoon.json`.

Команда запустит временный локальный сервер.
Она покажет прогресс и завершится после сохранения видео.
Для проекта со звуком используйте каталог сервера, содержащий его аудиофайлы.
Полный список параметров: `npm run render -- --help`.

## Если что-то не работает

**Chromium не найден.** Выполните `npm run setup:browser`.
Можно указать установленный Chrome через `CHROME_PATH` в `.env`.

**FFmpeg не найден.** Установите FFmpeg и проверьте `ffmpeg -version` и `ffprobe -version`.
Для нестандартной установки задайте `FFMPEG_PATH` и `FFPROBE_PATH`.

**В Linux нет видеокарты.** Задайте `STUDIO_SOFTWARE_GL=1` для экспорта.
Программное рисование может работать медленнее.

**WebGL недоступен.** Редактор покажет предупреждение и использует упрощённый рисунок Canvas2D.

**Не найден звук после переноса.** Импортируйте файл `.cartoon`, содержащий аудиофайлы.

## Границы первой версии

Это локальная студия, без учётных записей и публичного размещения.
Она не создаёт произвольное видео непосредственно из текста.
Дополнительный ИИ составляет сцены из доступных мест, персонажей и действий.
Студия пока не превращает фотографии в персонажей и не создаёт 3D.
